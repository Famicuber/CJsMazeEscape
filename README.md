# CJ's Maze Escape - Game Maker Source Code

---

This is the source code for the PC Game CJ's Maze Escape, a NES styled adventure game based on a very old Game Maker game, "CJ the Game: The Cookie Maze".

The source is mostly untouched from its original release aside from the removal of all files and references to the Alter Ego soundtrack that was used as placeholder during development, this was done under the wishes of the original composer, Richard "Kulor" Armijo, who wanted to maintain its CC BY-NC-SA license for his music as this release uses the MIT license.

I wrote this game back in 2015-2016 at 15-16 years old, before I was writing code on actual vintage hardware, I was mimicking it with the Steam version of Game Maker Studio.

One of the motivations for creating these games came from the disappointment I had with indie games at the time that "mimicked the retro 8-bit style", which in terms of accuracy was far from it. I wanted to write games that mimicked the hardware as close as I possibly could, even if it meant not being able to run on actual hardware.

The choice for remaking CJ the Game came down to being easy to develop with my vastly inexperienced coding skills and had frequent communication with the original author, HotelBrando at the time.

I gave myself a year to develop this game while I report on updates monthly with Brando, unfortunately, development exceed beyond its one year development plan. Wanting to move on to other projects, I've set a final deadline and made sure everything was done and working by that October 31st date, as a result, the code ended up being left in a messy state and the game's quality suffered.

As I was young and vastly inexperienced with the GML programming language, a lot of the coding practices presented in this repository is, to put it bluntly, absolutely terrible.

I only ever recommend checking out the code as an of example of "What NOT to do" when coding not only a game, but in general.

It is being uploaded as it is primarily for archival purposes.
